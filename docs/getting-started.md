# Welcome to Mist
Mist is a very basic engine that predominatly has rendering features above anything else.

Obviously, things are subject to change and I probably wouldn't actually use it for a serious project but if you want to peek through and see how things work you are welcome to. Also keep in mind that these docs may get outdated but I'll try my best to keep things up to date.

Documentation currently is limited and is mainly for me to list anything that is a quirk of the engine and wouldnt be immediately obvious.
